## System features I’m looking for

**Mandatory**:

- Encryption across all system drives
- Debian based OS
- Local and remote backup (3-2-1 strategy)
- Docker container based services

**Nice to have:**

- Journaling filesystem (ideally BTRFS)
- RAID-like redundancy
- Remote access

**Why:**

**Encryption** needs no explanation: it gives peace of mind and should be painless to configure with LUKS.
I wanted a system based on **Debian** because it’s what I have the most experience with, after using PopOS daily for years. (Maybe in the future I’ll fall into the Proxmox and Unraid rabbit hole. One must pace their chaos.)
The backup should follow a 3-2-1 strategy (system, local copy, remote copy). After all, I’ll be storing memories I deeply care about.

## The hardware

Given that this is still a proof of concept, I settled on reusing hardware I had lying around.

I’ll use my mother’s old (very old) laptop. It’s an Asus K53 from 2011, equipped with a 4-core (8-thread) i7, 8GB of RAM, one USB3 port, three USB2 ports, a SATA port, and a DVD drive.
In the main SATA port I’ll place a 250GB SSD, while the DVD Drive will be replaced, using an adapter, with a 750GB HDD. The only USB 3 port will be used to connect the local backup drive (1TB HDD).

As you can see, I’ve given up on RAID for the moment. This hardware is too limited in terms of expandability. Kudos to the MergerFS and Snapraid projects though; they may become useful in the future, so I’ll keep an eye on them.

Plus: in my opinion, a laptop is a nice choice for a small, light-usage home server, especially for students who move around a lot. It is fairly light, has an integrated battery (basically a cheap UPS), and comes with a screen and keyboard. Not strictly necessary, but a UI is always nice to have.

## The software

### Underworld

#### OS

For the OS, I settled on a simple **Ubuntu 22.04 LTS**. I wanted something reliable, with long support, that I could set and forget. Also, being a mainstream distribution, troubleshooting should be easier.

#### Filesystem

As for the filesystem, I had to settle on a boring **EXT4 LUKS encrypted** partition.
It is baffling that no major Debian-based distribution supports BTRFS, encryption, and the correct subvolumes by default.
I tried following several tutorials, but they all led to a lengthy process. That is not a problem by itself, but it becomes one during a system rebuild. Given that I’m still experimenting, I wanted to be prepared for that eventuality. So I settled on something reliable and streamlined. Trouble will come soon enough from other places.

#### Docker

Here comes Docker! I’ve always loved it, right until several containers start stepping on each other’s toes while fighting for network ports.
I didn’t want to deal with compose files all the time, so I decided to use a mix of **[CasaOS](https://github.com/IceWhaleTech/CasaOS)** and **Portainer** to deploy and manage containers.

**CasaOS** provides a **simple** and thoughtful user interface for the simple needs of a home user. Nothing more, and that’s fine for me. For anything that requires **serious** tinkering, there is good old **Portainer**.
CasaOS also provides easy deployment of popular images, already set up to not interfere with each other. Hurray.

#### Backup

For the moment, I’ll keep what I’m used to on my daily PopOS: **[Backintime](https://github.com/bit-team/backintime)** and **[Timeshift](https://github.com/linuxmint/timeshift)**.

Backintime deals with personal files, like documents, photos, and videos, while Timeshift deals with system files.

### Containers

Here is where the fun starts. CasaOS already provides most of the containers I need through an easy-to-use AppStore, although some tinkering will be required for a proper configuration.

What I’ll be using:

- **[Portainer](https://github.com/portainer/portainer)** : for advanced management of the docker environment
- **[Adminer](https://www.adminer.org/)** : for management of databases
- **[MariaDB](https://mariadb.org/)** : database which I’ll use for the more demanding applications
- **[Nginx Proxy Manager](https://nginxproxymanager.com/)** : for managing access to the system
- **[Cloudflared](https://github.com/cloudflare/cloudflared)** : for remote access via Cloudflare tunnels 
- **[PiHole](https://github.com/pi-hole/pi-hole)** : for local DNS management and network-wide ad blocking
- **[Syncthing](https://github.com/syncthing/syncthing)**  : P2P file sync app, used to keep in sync some folders across my various devices
- **[Nextcloud](https://github.com/nextcloud)** : fully fledged “self-hosted Google Drive/Docs/everything replacement”, a bit more than what I need at the moment, but nice to have
- **[Photoprism](https://github.com/photoprism/photoprism)** : provides a nice web UI to display my photo library
