The system has been running reliably for some time now, although there are still some things I need to address better, like an automated remote backup solution.

I hope you enjoyed this journey. For me, it has been a nice way to tinker with old tech I had lying around and reconnect with the self-hosting community.

Most importantly, I truly needed a system for making memories easily accessible, which is something I find myself really enjoying once in a while.
