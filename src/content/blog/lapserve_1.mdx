## Story time

Your phone is starting to fill up with pictures. They need to go somewhere. There are a few options:

- you can upload them to the cloud, but it can be pricey and compression ruins the quality.
- you can transfer them to a hard drive using a USB cable, but nah, too simple. Also, cables are friction, and friction is where good habits go to die.
- you can set up an automatic backup process when you come home. You are an engineer after all, right?

Well, challenge accepted. Oh, and since you’ll need some service running all the time anyway, maybe you can set up a whole server, right?

### TLDR

I needed a way to back up photos from my phone, so I overdid it and built a fully fledged home server in the process.
